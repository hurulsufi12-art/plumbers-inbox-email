# The Plumber's Inbox: A 120-Word Cold Email

A tiny Python program that writes a 120-word cold email (121 words including the subject line, 661 characters, ASCII) to `/output/entry.txt` for the make.fun bounty "The Plumber's Inbox: A 120-Word Cold Email".
